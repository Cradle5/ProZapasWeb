Хранилище: отдельный JSON-файл (аналог filesDir/notes.json) с атомарной записью «временный ключ → переименование», checksum каждой заметки (SHA-256), резервной копией для самовосстановления, корзиной с авточисткой через 30 дней и версионированным экспортом schemaVersion 2 (лабораторная 11, PRO-уровень).

Защищённый канал · HMAC-подпись запросов

Демо-сервер Прозапас принимает только запросы с подписью HMAC-SHA256(secret, method + path + sha256(body) + timestamp + nonce), окном ±30 секунд и уникальным nonce (replay-защита).

Канал готов. Запустите сценарии выше.

Живые метрики склада (аналог WebSocket wss://)

Поток остановлен.
Веб-аналоги сетевой лабы: запрет cleartext → Content-Security-Policy + политика смешанного содержимого браузера; certificate pinning → валидация сертификатов выполняется браузером (публичные CA, HSTS); HMAC-подпись, окно timestamp и replay-защита реализованы в коде выше и проверяются демо-сервером. MITM-эксперимент «против себя» в браузере: достаточно открыть DevTools → Network и увидеть, что запросы подписаны, а подменённое тело отклоняется сервером.
